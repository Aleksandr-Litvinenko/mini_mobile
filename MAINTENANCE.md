## 2026-08-02 — git-обвязка Unity-проекта

**Что добавлено**

- `.gitattributes` — которого не было вообще. Размечает Unity-YAML
  (`.unity`, `.prefab`, `.asset`, `.mat`, `.controller` и остальные)
  как `merge=unity`, помечает модели, текстуры, шрифты и пакеты `binary`,
  фиксирует `eol=lf` для YAML.
- `docs/GIT-UNITY.md` — что настроить у себя один раз: путь к UnityYAMLMerge
  для macOS / Windows / Linux, как решать конфликты в `.meta`, почему Force Text
  трогать нельзя и при каком размере репозитория имеет смысл вернуться
  к вопросу про Git LFS.

**Что изменено**

- `.gitignore` — добавлены стандартные для Unity исключения, которых
  не хватало: `ExportedObj/`, `AssetStoreTools*`, `sysinfo.txt`,
  `crashlytics-build.properties`, артефакты Rider и Visual Studio
  (`*.userprefs`, `*.suo`, `*.pidb`, `*.opendb`, `*.VC.db`),
  собранные пакеты (`*.apk`, `*.aab`, `*.unitypackage`, `*.app/`).
- `README.md` — раздел «Работа в git» со ссылкой на новый документ.

**Зачем**

Репозиторий на 7.5 МБ — самый крупный из всех, и почти весь объём это 39 моделей
`.fbx` и 38 текстур. Без `.gitattributes` git считает такие файлы обычными и
пытается разбирать их построчно. Отдельная беда — сцены и префабы: это YAML,
и обычный merge превращает конфликт в сломанную сцену, которая ещё и не всегда
падает сразу.

`merge=unity` включён для YAML, но **не** для `.meta` — намеренно. В `.meta`
лежат GUID-ы связей между ассетами; автоматически слитый `.meta` может тихо
переназначить ссылку, и это всплывёт через неделю в виде отвалившегося
материала, а не при merge. Явный конфликт честнее.

**Совместимость**

Проверено, что ни один отслеживаемый файл не попал под новые правила
`.gitignore` (`git ls-files -i -c` пуст) — ничего из истории не выпадает.

Файлы в `Assets/ThirdParty/` выведены из-под нормализации (`-text`): лицензии
Quaternius пришли с CRLF, и переписывать чужие файлы ради единообразия незачем.

Драйвер `merge=unity` требует однократной настройки в личном `~/.gitconfig`.
Если её не сделать, git не найдёт драйвер, молча откатится на обычный merge
и пометит конфликт — ровно то поведение, что было до этого коммита.
