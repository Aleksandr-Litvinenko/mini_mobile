# Mini Moba — битва на вулканах (Unity)

Онлайн MOBA в духе Mobile Legends: **1v1 по сети** или **тренировка против
компьютера**, три героя на выбор, большая арена между двумя извергающимися
вулканами, лава, башни, миньоны, прокачка — и **сенсорное управление** с
виртуальным джойстиком (играется и в мобильном браузере через WebGL).

Сеть: **Netcode for GameObjects** поверх WebSockets (десктоп ↔ браузер).
Сцена и префабы собираются кодом, а 3D-модели, текстуры и шрифт — **готовые
ассеты с лицензией CC0/OFL** (Quaternius, Kenney, ambientCG, Google Fonts).

## Режимы

- **1 на 1 — битва на вулканах**: сетевой матч против друга по IP.
- **Тренировка**: одиночный бой против бота (ИИ играет случайным героем:
  держит дистанцию, кайтит, использует скиллы, отступает лечиться, избегает лавы,
  покупает улучшения).

## Герои

| | Ксардас (маг огня) | Белиал (тёмный маг) | Аданос (маг воды) |
|---|---|---|---|
| **Q** | Огненный снаряд | Сгусток тьмы (замедляет) | Ледяная стрела (замедляет) |
| **W** | Телепорт к курсору | Похищение жизни | Живительный поток: лечение + ускорение |
| **E (с 4 ур.)** | Метеоритный шторм | Жатва душ (лечит за каждого врага) | Цунами (сильное замедление) |
| **Пассивно** | самая дальняя атака | вампиризм 12% | быстрый реген маны |

## Арена

Большая карта (~115×42): по **две башни** на сторону, базы с фонтанами,
шесть кустов-невидимок, **непроходимый лес и валуны**. Пол и лава — фотореалистичные
CC0-текстуры (ambientCG), лава течёт и светится. Каждые 45–75 секунд вулканы
извергаются: тряска, предупреждение и лужи лавы (60 урона/с) — сначала тёмное
пятно 2.5 с, потом кипящая лава на ~10 секунд.

Герои (маги Quaternius) и крипы (монстры Quaternius) — настоящие ригованные
модели со скелетными анимациями; башни и нексус — модели из Kenney Tower Defense Kit;
деревья — из Kenney Nature Kit.

## Управление

| | Десктоп | Сенсор (вкл. в меню) |
|---|---|---|
| Движение | WASD / стрелки / ПКМ | виртуальный джойстик |
| Атака | Пробел / ЛКМ | большая кнопка |
| Скиллы | Q / W / E (Q — в курсор) | кнопки (Q — в ближайшего врага) |
| Покупки | 1 / 2 / 3 | кнопки слева |

## Запуск

- **Редактор**: Unity Hub → Add → папка проекта → Play (сцена и префабы
  создадутся сами). Пересоздать: меню **MOBA → Rebuild All**.
- **Билд macOS**: **MOBA → Build macOS Player** → `Builds/MiniMoba.app`.
- **Мобильная версия (WebGL)**: **MOBA → Build WebGL (mobile)** →
  `Builds/WebGL`, затем раздать локальным сервером:
  `python3 -m http.server 8000 -d Builds/WebGL` — и открыть
  `http://<IP-компьютера>:8000` в браузере телефона. Телефон может только
  присоединяться к матчу (хостит десктоп) — в меню введите IP хоста.

## Как играть вдвоём

Оба выбирают режим «1 на 1» и героя. Один жмёт **«Создать игру (хост)»**,
второй вводит IP хоста и жмёт **«Войти»**.

- Один компьютер: два экземпляра `open -n Builds/MiniMoba.app`, IP `127.0.0.1`.
- Локальная сеть: IP хоста показан в меню и на экране ожидания.
- Интернет: VPN (Tailscale/Radmin) или проброс порта **7777** на роутере.
- CLI-флаги: `-host`, `-join <ip>`, `-training`, `-hero 0|1|2`.

## Код

- `Assets/Scripts/Units/Hero.cs` — три набора скиллов; `HeroBot.cs` — ИИ тренировки.
- `Assets/Scripts/Combat/LavaPool.cs`, `Game/GameManager.cs` — лава, волны, режимы.
- `Assets/Scripts/Game/MapBuilder.cs` — арена, вулканы, коллизии препятствий.
- `Assets/Scripts/UI/HudController.cs` — меню (режимы/герои) и HUD; `TouchHud.cs` — джойстик.
- `Assets/Scripts/Editor/MobaProjectBuilder.cs` — генерация сцены, префабов, частиц, сборки.
